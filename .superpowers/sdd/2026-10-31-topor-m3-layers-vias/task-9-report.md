- Design problem found and fixed (important, not in the note): dormant site vertices are free CDT vertices; the funnel bent at them, they were dropped from the taut sequence and the real obstacles the slot path wraps (and wire order) were lost (four-nets board: crossing wires). Fix: sketches and nesting are computed on a triangulation of the REAL obstacles (`sketch::build_layer_cdt_masked`, dormant site anchors deleted; cached per via occupancy in MetrState) from a polyline through the slot points of the path (`base_crossings`, `base_nesting`). `Relaxer::with_layers/replace` for leg-id wires.
- `graph.rs`/`search.rs`: free (dormant site) edge ends need no end clearance (`GEdge.free`, `end_gaps`), else every edge next to a site was permanently "overused".
- `wires.rs`: `Terminal::Site`; `terminal_of(Pour)` no longer a sentinel Via. `multigraph.rs`: `Arc<LayerSketch>`, Clone, `leg_layer`, `take_path`, `sync_anchors`, `LayerCtx.terminals`.

- Tests: new `engine/tests/route_layers.rs` (9), `negotiate_loop.rs` ported to the layered API + `site_rip_up_frees_owner_for_blocked_connection`; `route_engine.rs` M2 single-layer tests pin F.Cu only (`front_only`), pad-off-layer message updated, split-vertex test accepts the now-routable outcome (and checks clean), the eprom M2 stall/zero-slack test split into a 2-layer test (27/27, converged, no zero-slack, <= 67.1 mm) and a front-only clean test; decompose test expects `Terminal::Site`; Python: surface keys, `test_route_router_on_b_pads_fixture` (via written as through PCB_VIA), wall fixture closes B.Cu too.
