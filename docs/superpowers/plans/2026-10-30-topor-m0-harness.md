**Goal:** Build the M0 harness of 45 §1: a git repo with a KiCad-free Rust geometry kernel exposed as a PyO3 abi3 wheel, a Python/pcbnew harness that copies, rips, models, writes and DRC-checks boards, benchmark tooling, and the M0 gate (1000-arc fuzz → 0 KiCad DRC routing violations; hand-routed baseline images and metrics reproduced).

**Architecture:** Engine = pure Rust crate `topor-engine` (f64 nanometre geometry, exact distance primitives, uniform-grid spatial index, integer-nm quantisation) with a thin JSON-string PyO3 surface (`version`, `check_items`, `fuzz_items`, `arc_center_nm`). Harness = Python package `harness/` that uses the pcbnew SWIG module headless (test side only; the IPC adapter is M4) to build synthetic fixture boards, copy/rip benchmark boards, export a JSON board model + resolved rules to the engine, write segments/arcs/vias back, run `kicad-cli pcb drc`, render and compare. Everything crosses the Python↔Rust boundary as JSON with integer-nm coordinates in KiCad's Y-down frame; the engine flips Y once on import and once on export (20 §Conventions).

**Tech Stack:** Rust 1.96 (`cargo`, crates `serde`, `serde_json`, `proptest`, `pyo3 0.23` with `abi3-py39`, `rand` + `rand_chacha` for seeded fuzz), maturin (installed into `.venv`), Python 3.12 (`/usr/bin/python3`; no `python` on PATH), pytest, KiCad 10.0.8 (`pcbnew` SWIG, `/usr/bin/kicad-cli`), rsvg-convert, ImageMagick.

**Spec:** `docs/design/45-mvp-plan.md` (milestones, task table T0.1–T0.8 with tiers, orchestration §4–5, complexity budget §5a). ## Global Constraints

- Linux only; `/usr/bin/python3` (3.12.3) — never invoke `python`; all Python runs inside `.venv` created with `--system-site-packages` so `import pcbnew` works (31 §3.2: wheel tag `cp39-abi3-linux_x86_64`).
- Engine crate must not depend on KiCad, pcbnew or Topola code; the public surface is plain data in / plain data out (31 §3.4).
- Source boards under `~/work/kicad/projects` are **read-only**; the harness copies first and verifies sha256 before/after (benchmarks README). Unit tests use synthetic fixture boards generated by `harness/fixtures.py`; benchmark boards appear only in gate steps (`tests/gate/`).
- No system package installs (`pip install` only into `.venv`; maturin from PyPI into `.venv`).
- Arc-centre agreement with KiCad: ≤ 100 nm (user decision 2026-10-30: 1 nm is overkill; JLCPCB min spacing 0.09 mm, routing margin 5 µm); no bit-exact port of `CalcArcCenter` needed.
- Coordinates: KiCad IU = 1 nm, `i32`; engine math in `f64` nm; output integers rounded once; shared chain endpoints bit-identical (23 §4.4).
- Build margin `ε_build` = **5 000 nm** default, allowed range 1 000–10 000 nm, +5 000 nm near polygonised zones/custom pads (23 §4.1); never spend KiCad's `DRCEpsilon` 0.5 µm (23 §2).
- Degenerate arcs: sagitta < 5 nm or chord < 10 nm → emit a segment (23 §4.3); `mid` = angular midpoint, never chord midpoint (23 §4.5).
- KiCad DRC command fixed: `kicad-cli pcb drc --format json --refill-zones --all-track-errors --exit-code-violations -o <json> <pcb>`; exit 0 or 5 are both successful runs (30 §4).
- Render command fixed: `kicad-cli pcb export svg -l F.Cu,B.Cu,Edge.Cuts --mode-single --page-size-mode 2 --exclude-drawing-sheet -o <svg> <pcb>` on a copy with zone fills removed, then `rsvg-convert -h 1100` (benchmarks README §6).
- JLCPCB profile (30 §5.2): width 0.20 mm, clearance 0.15 mm, via default 0.30/0.60 mm, smallest automatic via 0.25/0.45 mm, drill list 0.20/0.25/0.30/0.40/0.50/0.80/1.00 mm, routing vias 0.25/0.30/0.40/0.50 mm (0.20 avoided, 0.15 only on explicit request), via-hole-to-track 0.2, PTH-hole-to-track 0.35, NPTH-to-track 0.25, hole-to-hole via 0.25 / pad 0.5, copper-to-edge 0.3, V-cut 0.5 mm. Precedence: custom rule → netclass → board setup → profile; the profile only fills gaps.
- Width resolution order (30 §5.1): custom `track_width` rule → non-`Default` netclass width → existing copper median before rip → settings table → `Default` width; board minimum is a floor.
- Complexity (45 §5a): no exponential/factorial algorithms; every loop has an iteration cap and the run a wall-clock budget with anytime behaviour (best result so far on timeout); spatial index mandatory — no all-pairs O(n²) clearance checks outside tests; benchmarks record runtime.
- Budgets are hypotheses to be proven, never relaxed unilaterally (45 §5a): if a stage cannot meet its complexity target without exponential/factorial search, or a runtime target is still missed after **one** F diagnosis round, the coordinator STOPS and escalates to the user with measurements (scaling numbers, a profile of where time goes, options with their quality cost). This applies to every gate step below.
- Existing copper is data, not waste: the board model always carries existing tracks/arcs/vias with net and locked flag; ripping is an option (`existing_copper: fixed | smooth | rip`, default `fixed`), and a routing scope (`nets`, `netclasses`, `pads` like `"U1.3,J2.7"`, `footprints`, `area`, `unrouted_only`) limits what is routed — everything outside the scope is fixed. A dangling end of a hand-drawn track is a route start (same layer and width, G1 from the hand trace's end direction, hand trace unchanged) — M0 detects them, M2 routes from them.
- Compact output: every DRC/benchmark summary ≤ 20 lines; full JSON stays on disk (45 §5).
- Engine options carry `partial_routes: bool` (default `false`) from M0 on; DRC summaries classify `track_dangling`, `via_dangling` and `unconnected_items` as "incomplete" separately from real violations.
- Plugin dir `~/.local/share/kicad/10.0/plugins/<identifier>/` (resolution rule 31 §3.3 step 2); venv `~/.cache/kicad/10.0/python-environments/<identifier>`; `requirements.txt` uses `--find-links wheels` + a pinned engine version + `kicad-python>=0.8,<0.9` (pinned from M0, user decision 2026-10-30; 0.8.0 is current on PyPI); KiCad pip runs `--only-binary :all:`.

## Review Focus

1. A legacy KiCad-5 project (eprom-to-kernal has `.pro`, no `.kicad_pro`): rule resolution must still produce edge clearance 0.5 mm and Default 0.2/0.25 mm from pcbnew's loaded defaults instead of crashing on the missing JSON. → test `test_rules_legacy_project_without_kicad_pro` (Task 10).
2. An arc so flat that KiCad would round it to a line (chord 50 mm, sagitta 3 nm): must be written as a segment, not as an arc with a centre kilometres away. → `prop_flat_arc_becomes_segment` (Task 5).
3. A pad with a local clearance override larger than the netclass clearance: fuzz items placed at netclass clearance next to it would violate DRC. → `test_pad_local_clearance_override_wins` (Task 10) and the fuzz placement uses `required_clearance(pad)` (Task 14).
4. A net-tie footprint: its pads carry two nets and overlap; the model must not report the tie's pads as unroutable and must mark its internal copper as non-obstacle for the tie's nets. → `test_model_net_tie_groups` (Task 9).
5. `kicad-cli` exits 5 for warnings only (e.g. two `track_dangling` warnings and nothing else): the harness must treat that as a clean routing result, not a failure. → `test_summary_only_incomplete_is_clean` (Task 12).

// engine/tests/tangent_props.rs  (proptest; coordinates in nm, ranges ±50_000_000, radii 50_000..5_000_000)
proptest! {
  #[test] fn prop_point_tangent_is_perpendicular(p in vec2(), c in circle()) {
    prop_assume!((p - c.c).len() > c.r * 1.001);
    for s in [Orient::Ccw, Orient::Cw] {
      let t = point_circle_tangent(p, c, s).unwrap();
      prop_assert!(((t - c.c).len() - c.r).abs() < 1e-3);        // on the circle (nm)
      prop_assert!((t - c.c).dot(t - p).abs() < 1e-3 * c.r * (p - c.c).len());   // radius ⟂ tangent
      prop_assert!(s.sign() * (t - p).cross(c.c - t) > 0.0);     // centre on σ side
    }
  }
  #[test] fn prop_bitangent_touches_both_and_respects_sigma(c1 in circle(), c2 in circle(), s1 in orient(), s2 in orient()) {
    prop_assume!((c2.c - c1.c).len() > c1.r + c2.r + 1000.0);
    let seg = bitangent(c1, s1, c2, s2).unwrap();
    let t = (seg.b - seg.a).unit().unwrap();
    prop_assert!(((seg.a - c1.c).len() - c1.r).abs() < 1e-2 && ((seg.b - c2.c).len() - c2.r).abs() < 1e-2);
    prop_assert!(s1.sign() * t.cross(c1.c - seg.a) > 0.0 && s2.sign() * t.cross(c2.c - seg.b) > 0.0);
    prop_assert!((seg.a - c1.c).dot(t).abs() < 1e-3 * c1.r);     // tangent ⟂ radius
  }
  #[test] fn prop_inner_bitangent_infeasible_when_overlapping(c1 in circle(), c2 in circle()) {
    prop_assume!((c2.c - c1.c).len() < c1.r + c2.r - 1000.0 && (c2.c - c1.c).len() > (c1.r - c2.r).abs() + 1000.0);
    prop_assert!(matches!(bitangent(c1, Orient::Ccw, c2, Orient::Cw), Err(GeomError::Infeasible)));
    prop_assert!(bitangent(c1, Orient::Ccw, c2, Orient::Ccw).is_ok());  // outer still exists
  }
  #[test] fn prop_arc_from_tangent_points_roundtrip(c in circle(), a1 in 0.0..6.283, a2 in 0.0..6.283, s in orient()) {
    let t_in = c.c + Vec2{x: c.r*a1.cos(), y: c.r*a1.sin()}; let t_out = c.c + Vec2{x: c.r*a2.cos(), y: c.r*a2.sin()};
    let arc = Arc::from_tangent_points(c.c, c.r, s, t_in, t_out);
    prop_assert!((arc.start() - t_in).len() < 1e-3 && (arc.end() - t_out).len() < 1e-3);
    prop_assert!(arc.sweep >= 0.0 && arc.sweep < 6.2832);
    prop_assert!(((arc.mid() - c.c).len() - c.r).abs() < 1e-3);
    prop_assert!(arc.contains_dir(arc.mid()) && (arc.length() - c.r*arc.sweep).abs() < 1e-6);
  }
}
