# M1 design note — Tasks 5–6: taut chain (`taut.rs`) and stacks/relaxation (`relax.rs`)

Refs: 20 §1–4 (inflation ρ, σ), 21 §2–5 (bitangents, arcs, slack, stacks), 25 §2 (loop, ε-band). Interfaces as in the briefs; see **Deviations**.
Conventions: math frame, nm, `σ = Ccw ⇔ cross(t, C − P) > 0` (centre on the **left** of travel `t`); `Arc::from_tangent_points(c, r, σ, t_in, t_out)` sweeps in direction σ.
All candidate lists are sorted (anchor index / (wire, prim)) before use, so results never depend on `HashMap`/`Grid` iteration order.

## 1. `chain_geometry(start, goal, seq, env)` — 21 §2–3 verbatim
1. Drop exempt anchors from `seq` (`env.exempt_anchor`); concentric anchors (bit-equal centres, e.g. via copper + its hole) count as one member — first wins.
2. `InsideObstacle`: for P ∈ {start, goal}: `query_anchors(layer, bbox(P).grow(G))`, `G = env.query_grow()`; any non-exempt anchor with `|P − c| < ρ_a` (`env.rho_anchor`), or non-exempt wall with `dist(P, core) < ρ_w`, → `Err(InsideObstacle(label))`. Dyn obstacles are not checked here.
3. Nodes `N_0 = Circle{start, 0}`, `N_i = Circle{c_i, R_i}` with `R_i = env.stack_radius(seq[i])` (≥ ρ by construction), `N_{k+1} = Circle{goal, 0}`. Segments `s_i = bitangent(N_i, σ_i, N_{i+1}, σ_{i+1})` for i = 0..=k (terminal σ: use the neighbour's; it is ignored for r = 0 — Deviation D1). Arc i = `from_tangent_points(c_i, R_i, σ_i, s_{i−1}.b, s_i.a)`.
4. Error map: `GeomError::Infeasible | Degenerate → Infeasible("a_i label ↔ a_j label")` (needed inner tangent missing / concentric), `GeomError::InsideObstacle → InsideObstacle` (a terminal inside a stack-grown circle).
5. Zero-sweep arcs (`R·Δθ < 1 nm`) are omitted from `prims` and the two adjacent collinear segs are merged (so `pattern()` never has `"SS"`); the anchor stays in `seq` until §2 drops it. `length = Σ prim.length()`. `Δθ > π` is legitimate and kept.
Mapping prims ↔ seq (needed by relax): walk `prims`; each `Arc` advances a cursor in `seq` to the first entry with bit-equal centre and equal σ.

## 2. `tauten` — fix-up loop (21 §4, 25 §2 step 3)
`for pass in 0..TAUT_PASS_CAP { chain = chain_geometry(…)?; changed = drop_pass() || add_pass(); if !changed { return Ok(chain) } }` → `Err(Cap)`. If `seq.len() > MAX_SLEEVE (2000)` at any time → `Err(Sleeve)`. Every pass is O(k · q) (k anchors, q = grid query cost); the cap is the sole termination guarantee (no monotone length argument exists once stack radii and dyn obstacles move); empirically 1–3 passes.
**Queries.** Static: `query_anchors/query_walls(layer, prim.bbox().grow(G))` then the exact test; dyn: `env.dyn_near(prim.bbox().grow(G))` (impl returns same-layer, other-net prims whose bbox overlaps the given box). `G = env.query_grow()` must be ≥ `ρ − r_core` of every obstacle and ≥ every `dyn_clearance` (Deviation D2).
**Penetration** (static anchor a): `dist(prim, c_a) < ρ_a − 1 nm`; wall w: `dist_prim(prim, core_w) < ρ_w − 1 nm`; dyn d: `dist_prim(prim, d.prim) < env.dyn_clearance(d) − 1 nm`. Members (anchor index or bit-equal centre already in `seq`, any σ) are skipped. Hysteresis: add at `< ρ`, drop at `≥ R + SLACK_BAND_NM (10 µm)` — an anchor added in one pass sits at exactly R and cannot be dropped in the next, and a dropped one leaves a shortcut ≥ R + band that cannot re-trigger add; flip-flops can then only come from neighbour changes, bounded by the cap.
**Drop rule** — single left-to-right sweep over interior anchors with the *current* neighbours p, q (after a drop, the next anchor's left neighbour is the survivor). Anchor i with neighbours (circles with their σ, R) is slack iff all of:
(a) `s = bitangent(p, σ_p, q, σ_q)` exists; (b) side: `σ_i · cross(t, c_i − s.a) > 0`, `t = s.dir()` — this is the turning-angle sign test: the shortcut would need a turn of sign σ_i to wrap a_i, so a_i lies on its wrap side; (c) `point_seg(c_i, s) ≥ R_i + SLACK_BAND_NM`; (d) current arc sweep `Δθ_i ≤ π` (a doubling-back wire's swept region contains its own core; never drop it); (e) no non-exempt static anchor centre strictly inside triangle (c_p, c_i, c_q) (candidates from `query_anchors(triangle bbox)`); (f) the shortcut `s` penetrates no non-member static/dyn obstacle (same test as above).
Why the centre triangle: for point neighbours and Δθ ≤ π the region swept between old path and shortcut lies inside the triangle exactly (both tangents leave p within the wedge ∠(q, p, c_i), the disk of a_i is on the far side of the old path). With circle neighbours the old/new tangents are offset by ≤ max(R_p, R_q) from the triangle edges, so a core centre within that band can be missed. Risk bound: a missed core X is then either penetrated by the shortcut (caught by (f) or by the next add pass) or passed DRC-clean on the other side — a homotopy change with no copper violation; a crossed *wire* is a dyn penetration → add → resolved or `Cap`; anything left is caught by the Task 8 self-check, whose fallback granularity is the wire.
**Add rule** — for every prim of the chain and every penetrating non-member obstacle, the anchor to add is: static anchor → itself; wall → the endpoint anchor `e ∈ ends` minimising `dist(prim, c_e)` (if that one is already a member, the other; both members → skip: the inflated wall is the hull of its endpoint circles, so wrapping both endpoints gives the outer tangent parallel to the wall at ρ — a long wall grazed in the middle takes two passes); dyn arc → `d.anchor`; dyn seg → both `d.adjacent` (those `Some` and non-member) — our chain then wraps the same anchors at the stack radius and runs parallel to that wire's segment at `w_j/2 + c + ε + w_k/2` (21 §5 "parallel runs"), i.e. the stack formula emerges from the add rule. σ for each added anchor with centre C: `P` = closest point on the prim to C (seg: clamped projection; arc: angle clamp to the sweep), `t` = travel tangent at P, `σ = Ccw if cross(t, C − P) > 0 else Cw`; exact 0 → use `cross(t, C − prim.start)`, still 0 → Ccw. Insert position = path position: a seg between seq positions i−1 and i inserts at i; an arc at i inserts at i if the closest point is in the first half of its sweep, else at i+1. All additions of a pass are collected as `(pos, fraction along prim, anchor)`, sorted, de-duplicated by anchor (first in path order wins), then inserted back-to-front. Same net is never "non-member": `dyn_near` already excludes it (mirror `Checker::is_exempt`: `d.net != 0 && d.net == net`).

## 3. Task 6 — `Stacks` and `relax`
**Stacks (per layer).** `order[(A,σ)]` from `stack_order` (Task 4; wire ids = positions in `wires`); `members[(A,σ)]` = wires whose current chain has an arc at (A,σ) with sweep > 0 (`set_members` after each tauten; a wire whose tauten failed has no memberships). Initial membership = every listed wire (21 §5 conservative rule) so first-iteration radii are already stacked. Position of wire k in the stack: index in `order` if listed, else appended after all listed wires in increasing id (an anchor reached only through the add rule is outermost — any nested assignment is DRC-consistent at the anchor; wrong crossings are the self-check's job). `radius(a, k)`: `inner` = members positioned before k; walk them in order computing `R_j = max(ρ_j, max_{i<j}(R_i + w_i/2 + c(i,j) + w_j/2))`, return `R_k` likewise; `ρ_j = obs.rho_anchor(layer, a.anchor, net_j, w_j)` (= r_A + c(A,j) + ε + w_j/2); `c(i,j) = 0` if same net else `obs.clearance(net_j, Track, net_i, obs.clearance(net_i, Track, net_i, 0)) + obs.margin()` (= max(clr_i, clr_j, min) + ε). O(m²) per call with m = members at one anchor side (≤ wires), no board-wide pairs. Both stacks (A,Ccw) and (A,Cw) exist; Task 2's start ≤ goal direction normalisation makes σ encode the geometric side consistently.
**Env per wire k** (`WireEnv` borrowing `obs`, the layer's `Stacks`, the layer's dyn grid + store, `wires`): `rho_* = obs.rho_*(layer, idx, net_k, w_k)`, `exempt_* = ObstacleSet::exempt(o.net, &o.tie_nets, net_k)`, `stack_radius(a) = stacks.radius(a, k, wires, obs)`, `dyn_clearance(d) = c(k, d.wire) + ε + w_k/2 + d.width/2`, `query_grow() = obs.query_grow()`.
**Dyn store.** Per layer: `Vec<Vec<DynObstacle>>` by wire + `Grid<(wire, prim_idx)>` (cell = `obs.query_grow()`), bbox stored with the item so `remove(bbox, item)` matches. Before tautening k: remove k's items; after `Ok(chain)`: rebuild k's `DynObstacle`s from the prims ↔ seq mapping (§1) and insert. A failed wire contributes nothing (its hand copper is checked by the Task 8 self-check, which must include fallback wires' kept copper).
**Loop (Gauss–Seidel).** Wire order: (width desc, net asc, id asc), fixed. `chains` start as `Err(Sleeve("not relaxed"))`, `seq_k` = `sketches[k].seq`.
```
for it in 1..=opts.relax_iter_cap { changed = false
  for k in order { if Instant::now() >= deadline { timed_out = true; return best so far }
    dyn.remove(k); res = tauten(start_k, goal_k, seq_k, &env_k)
    match res { Ok(c) => { changed |= !same(prev_k, c); seq_k = c.seq; dyn.insert(k, c); stacks.set_members(k, arcs(c)) }
                Err(_) => { changed |= prev_k.is_ok(); seq_k = sketches[k].seq /* retry from the sketch */; stacks.set_members(k, []) } }
    chains[k] = res }
  iterations = it; if !changed { converged = true; break } }
```
`same`: equal prim count, same kinds, endpoints/centre/radius within 1 nm and `|Δsweep|·r < 1 nm`. Cost per iteration O(Σ prims · passes · q); expected 2–3 iterations (build, re-stack, confirm); the cap and the deadline (checked before every wire) are the guarantees; `timed_out` returns the last complete chains (anytime). A chain-to-chain conflict that the add rule cannot express (member anchor reached again) persists to the self-check and falls back that wire only.

## Deviations (minimal fixes)
- **D1 `geom/tangent.rs::bitangent`**: with `r = 0` the side test `s.sign() * t.cross(c.c − seg.a) > 0` is `0 > 0` → every terminal segment returns `Infeasible`. Fix: `(c1.r == 0.0 || …) && (c2.r == 0.0 || …)`; a point has no side.
- **D2 `Env::query_grow(&self) -> f64`** (new required method) and `ObstacleSet::query_grow()` (returns the private `cell` = max_w + max_clr + margin, which bounds every `ρ − r_core` and every dyn clearance) plus `ObstacleSet::margin()` (ε for `c(i,j)`). Without a pre-grow value the exact bbox filter in `query_*` drops every penetrating anchor.
- **D3 `relax`** cannot call `stack_order` (needs the per-layer `LayerSketch`) and `AnchorRef` is only unique per layer: add `orders: &HashMap<u32, HashMap<AnchorRef, Vec<usize>>>` (one `stack_order` result per layer, computed by Task 8); `Stacks` is instantiated per layer. `sketches` is aligned with `wires`.
- **D4** wall test values as in §4.
